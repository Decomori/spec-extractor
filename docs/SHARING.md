# GitHub에 이 기능 하나만 공유하기

## 현재 상태

파일은 배포 가능한 로컬 소스입니다. **이 문서 자체가 GitHub 게시 완료를 뜻하지 않습니다.**
저장소 생성·업로드는 아래 명령이 성공한 뒤에만 완료됩니다. 공개 디렉터리 제출도 별도입니다.

## 준비

Git, GitHub CLI(`gh`), Python 3.10+가 필요합니다. 본인 기기에서 `gh auth login`으로
로그인하고 `gh auth status`로 계정을 확인합니다. 키·토큰을 대화나 저장소에 붙이지 않습니다.

먼저 파일 목록과 검사 결과를 확인합니다.

```bash
python3 tools/validate_package.py
python3 -m unittest discover -s tests -v
python3 tools/publish.py --plan
```

검토한 이 패키지 하나를 **새 공개 저장소**에 생성합니다. 명령은 실행자가 명시적으로
게시를 승인하는 동작입니다. 로그인된 개인 계정에 `spec-extractor` 저장소를 만듭니다.

```bash
python3 tools/publish.py --visibility public --confirm
```

비공개로 먼저 만들 때는 `--visibility private`를 사용합니다(기본값도 private).
특정 계정인지 강제 확인하려면 `--owner YOUR_LOGIN`을 추가합니다. 이 옵션은 계정을
바꾸지 않으며 현재 인증 계정과 다르면 중단합니다.

도구는 허용된 소스 파일만 임시 폴더에 복사하고 새 Git 저장소를 초기화한 다음 `gh repo create`
를 호출합니다. 기존 원격 저장소가 있으면 중단하며, force push/삭제/기존 파일 덮어쓰기를
하지 않습니다. 회사 자료, .git 이력, .env, 로컬 실행 결과는 업로드 목록에 포함하지 않습니다.
패턴 검사는 완전한 보안 감사가 아니므로 파일 목록은 사람이 검토해야 합니다.

## 받는 사람에게 보낼 문구

성공 출력의 실제 GitHub URL과 함께 전달합니다.

```text
여기는 Spec Extractor 스킬/플러그인 저장소야.
README.md와 docs/INSTALL.md를 읽고 현재 환경에 맞게 설치해줘.
플러그인 또는 독립 스킬 중 하나만 설치하고 다른 설정은 보존해줘.
도구나 권한이 없으면 가능한 범위와 별도 준비가 필요한 부분을 알려줘.

<실제 게시된 GitHub URL>
```

## 공개 디렉터리와는 별개

GitHub 저장소 배포는 소스 공유 및 지원되는 로컬 설치 경로입니다. ChatGPT 공개
플러그인 디렉터리는 별도 제출·검토·게시 경로입니다. 필요에 맞는 게시자 정보, 아이콘,
개인정보 처리 안내의 공개 URL, 배포 조건과 호환성 시험 등 현재 요구 사항을 확인해야
합니다. 이 패키지는 공식 승인·모든 계정 지원·웹/모바일 무설정 사용을 주장하지 않습니다.

## 유지보수

각 프로젝트를 따로 버전 관리합니다. `VERSION`과 plugin.json의 버전을 함께 올리고,
CHANGELOG에 변경과 호환성 영향을 적습니다. 개인 프로젝트 설정은 설치 폴더 밖에 두며
소스 업데이트가 고객 작업물을 수정하지 않도록 합니다. 중요한 변경은 새 버전으로
테스트한 뒤 배포합니다. 다른 두 저장소의 존재·버전에 의존하지 않습니다.
