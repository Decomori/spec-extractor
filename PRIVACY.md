# Data processing — Spec Extractor

This repository itself runs no hosted service and collects no telemetry. Local scripts
write only their explicitly requested outputs/installation files. Product Visual helpers
process local images and strip EXIF/GPS in exports; Spec Extractor helpers validate/export
local JSON; SEO URL mode contacts the exact public sites being audited and writes local
source snapshots. A host AI or connected image/document service processes the inputs
under that host/service's own terms. "Local helper" does not mean the entire AI workflow
is offline or that the publisher controls the host's data retention.

Do not send proprietary images or documents to an additional third-party service without
authorization. File-reading and app permissions belong to each receiving user/account.
No credentials are supplied by the publisher, and this plugin cannot transfer a login.

Audit results can contain sensitive URLs, page text or business information. Extraction
results can contain proprietary specifications and source names. Keep outputs private by
default and review/redact them before sharing. The included examples are synthetic.
There is no automatic cloud upload by the helpers except the separately invoked,
explicitly confirmed GitHub publication command for the reviewed package source.

This file documents this source package; it is not a claim of OpenAI directory approval
or a substitute for a publisher's applicable public privacy policy when submitting.
